# 1. Vue d’ensemble de gnark

gnark est une bibliothèque Go pour concevoir des circuits zk-SNARK à haut niveau. Elle sépare la définition du circuit, sa compilation, le proving et la vérification.

Le dépôt s’appuie sur gnark-crypto pour l’arithmétique de corps et les primitives cryptographiques.
